Shared Rules

跨專案共同治理原則

Evidence > Self-report
Agent 說完成，不等於真的完成。
Execution ≠ Completion
做過只是執行；驗證通過才有資格升級狀態。
Dashboard ≠ Truth
畫面是投影，GitHub / Evidence / Runtime 才是依據。
Model ≠ Identity
模型可以替換，角色、規則與契約不能跟著漂移。
CI ≠ Real Machine
CI 綠燈不等於真機、硬體、量測與實體環境都驗證過。
Human Final Authority
高風險、不可逆、正式發布與範圍裁決由 Human 決定。
